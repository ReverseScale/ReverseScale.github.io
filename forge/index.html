01 / WHY

The gap

Most learning tools forget the work that made the question matter.

Generic courses know the topic. Your project knows the pressure. Forge connects both.

A useful technical question is rarely isolated from the codebase, the constraints, or the decisions that exposed the gap. Forge keeps those signals close, then uses the conversation itself to build a durable picture of what you understand.

01Ground the challenge

Use active technical direction and project context as the seed.

02Probe the boundary

Test failure semantics, tradeoffs, and transfer—not recall.

03Preserve the change

Carry the new evidence into ability memory and spaced review.

02 / PRODUCT

What you can do

A training workspace that adapts to the work you are doing now.

Choose what matters, bring in the project that gives it context, then practice through a coached session. Forge carries the evidence forward instead of resetting after every answer.

09Instrumentation

Per-agent token accounting

The orchestrator normalizes provider usage, attributes input and output tokens to the active Agent run, and resets the counter at every handoff.

Cost evidence stays separate from operational evidence, so a slow or failed run is not mistaken for an expensive one—and either signal can evolve independently.

05 / BOUNDARY

Deliberate boundaries

A practice system,
not a leaderboard.

Forge optimizes for useful reflection and stronger transfer into real engineering work—not streaks, volume, or public ranking.

Forge does

Make learning specific.

  • Use real work as the learning seed
  • Challenge vague but plausible reasoning
  • Build durable personal learning history
Forge does not

Turn growth into theater.

  • Replace project-level code review
  • Prescribe one universal curriculum
  • Optimize for question volume or ranking
MVP / implemented

The end-to-end backend, REST API, Next.js interface, MCP surface, four-agent topology, and isolated learning data model are implemented.

The compounding effect

Every session should leave the next question better informed.
