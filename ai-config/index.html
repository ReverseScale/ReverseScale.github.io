Why it exists

AI tooling should feel like infrastructure, not folklore.

Personal setup often drifts across machines. Multi-agent work often hides ownership and completion in chat. AI Config gives both problems one answer: version the durable configuration, then make collaboration state explicit.

Built-in guardrails

Autonomy with an edge.

Coordination is useful only when its authority, state, and completion boundary stay visible.

01 / SOURCE

Versioned configuration

Hooks, Skills, MCP definitions, and machine setup share one reviewable source of truth.

02 / AUTHORITY

Explicit permissions

Each agent receives a named role and the smallest workspace access its task requires.

03 / EVIDENCE

Auditable outcomes

Tasks, leases, artifacts, and handoffs make progress inspectable beyond a chat transcript.

System boundary

Local-first by design.

A Supervisor owns Room state. Drivers resume model sessions. A strict workflow defines who can act, what they depend on, and what must exist before work is complete.
